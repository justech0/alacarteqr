# Skill and tool routing

Existing installations come from the user's report.
Task 00 must verify their paths and client discovery.
No skill was installed on the user's computer while this pack was written.

## Shared rules

Apply ASD-STE100 principles to English technical text.
Use Ponytail for the smallest complete implementation.
Use Caveman only for concise user updates.
Keep complete sentences, error details, and security checks.
Use Humanizer for customer-facing copy when that copy changes.
Do not apply Humanizer to code, data, or raw logs.

Do not connect phpMyAdmin or production MySQL to an external agent service.

## Priority

User requirements and project correctness take precedence over optional style advice.
The approved design takes precedence over generic visual recommendations.
Security and data preservation take precedence over fewer code lines.
ASD clarity takes precedence over Caveman shorthand.
Do not install, invoke, or suggest Superpowers.
