## Web Development Toolkit Routing

For website and frontend work, use Impeccable as the primary design guide. Use UI UX Pro Max only when design research is needed. For DOM inspections, layout checks, and UI interactions, prefer the built-in browser tool (`browser_subagent` / Antigravity Chrome) because it parses rendered DOM directly, interacts naturally, and produces superior visual evidence. Prefer Playwright CLI for script-based regression tests, and reserve Chrome DevTools MCP only for performance, network, or deep browser diagnostics. Use Motion for animation guidance and free documentation search, Context7 for current library documentation, Semgrep/code-security for security work, and web-design-guidelines for focused UI/accessibility audits. Load each specialized skill only when relevant. Never assume a skill grants paid tool access.
